## 원칙 (메인 확정)

**P1. 움직임 자체가 수학적 뜻일 때만 끌기.** 끌기는 장식이 아닙니다. 옮기는 동작이 곧 수학일 때만 씁니다.

| 끌기로 (움직임 = 뜻) | 탭으로 (고르기·답하기) |
|---|---|
| 저울에서 추를 내리고 올리기(양쪽에 같은 일) | 채점 '확인하기' |
| 순열 = 칩의 **자리 바꾸기** | 3개 이상 고르기 |
| 2개 고르기 = 두 물건을 **선으로 잇기** | 분수 비교의 답(크다·같다·작다) |
| 분수 비교 = 한 막대를 다른 막대에 **겹쳐 대 보기** | 구간의 빈 점/찬 점 바꾸기 |
| 수직선 점프 = 점을 그만큼 **옮기기** | 파스칼·수형도처럼 '보여 주기'인 것은 조각에서 뜻 있는 동작을 찾지 못하면 탭 유지 |
| 벤 다이어그램 = 원소를 영역으로 **분류** | |

**P2. 버튼은 두 종류로 나눈다.** 결과를 대신 그려 주는 버튼("다음 이동 보기", "1000 빼기")은 없앱니다. **채점용 '확인하기'는 유지**합니다(놓자마자 채점하면 이리저리 대 보다 맞히게 됨).

**P3. 목표 판정은 손을 뗀 자리에서만.** 끄는 도중 지나가다 달성되지 않습니다. **숨긴 정답에는 가까워짐 신호가 없습니다**(색 변화·"거의 다 왔어요"·떨림 금지 — 있으면 계산 대신 더듬어 찾게 됨).

**P4. 탭 대체 버튼은 기본 숨김.** 끌기를 몇 번 놓치면(제안 2번, 기존 '넘어가기' 기준과 같게) "눌러서 하기"가 나타납니다. 키보드 방향키는 늘 동작합니다.

**P5. 부품 전환은 '부품 + 그 부품을 쓰는 단원 글'을 한 묶음으로.** 화면만 바뀌고 글이 옛 버튼을 가리키는 상태를 만들지 않습니다.

**P6. 합격 기준은 "차이 0"이 아니라 세 가지.**
1. 달라진 검산 항목이 **목록으로 나오고 하나하나 이유가 설명됨**(기준선 비교 스크립트: 새로 생김·사라짐·바뀜).
2. 전체 검산 통과.
3. **장면 id 불변**(학습자의 진행 기록이 장면 id 로 저장됨 — 기존 id 삭제·변경 0).
동작을 안 바꾸는 리팩토링 커밋에만 "차이 0"을 요구합니다.

**P7. 검산 원칙 유지.** 화면에 보이거나 채점에 쓰는 값은 앱 모델이 계산하고 sympy 가 같은 결과를 다시 계산합니다. 끌기로 생기는 중간 상태도 포함합니다.

**P8. 끄는 동안 화면 전체를 다시 그리지 않는다**(React 렌더 0회, 기존 방식). 기울기 같은 움직임은 CSS 전환으로 충분하면 그것으로 하고, 모자랄 때만 자체 계산을 씁니다.

**P9. 부품당 동시 끌기는 1개**(두 손가락이 다른 손잡이를 동시에 끌지 못하게 잠금). 저울만 양쪽 접시를 동시에 끄는 것을 허용할지 시안에서 정합니다.

**P10. 무리수 값의 허용 오차 규칙.** 목표값이 유리수면 분수로 정확히 비교합니다(기존). 무리수면 허용 오차를 두되, 형식 검사가 "끄는 간격으로 닿는 자리 중 오차 안에 드는 것이 정답 자리 하나뿐"임을 확인하고, sympy 가 정확한 값으로 같은 판정을 되풀이합니다.

- **끝났는지 확인**: 화면의 합 = sympy 합(분수 일치), n 을 키우면 정적분 값에 다가감 / 넓이 = sympy `integrate` / P6 / 화면 점검(슬라이더 끄는 중 프레임 시간).
- **위험**: n 이 크면 느려짐 → n 상한을 형식 검사로.

### ④ 확률·경우의 수

- **깨닫게 할 것**: 경우는 직접 만들어 봐야 "빠짐없이, 겹치지 않게"가 보인다. 많이 던질수록 비율이 이론값에 다가간다.
- **할 일**
  - count: 순열 = 칩 자리 바꾸기, 2개 고르기 = 두 물건 선으로 잇기, 벤 = 원소를 영역으로 분류(전체집합·여집합 포함). 단계마다 다른 물건, 같은 물건 여러 개, 중복조합, 공·칸막이 그림, 조건 강조.
  - simulate: **직접 하나씩 던지기 → 누르고 있으면 계속 던져짐**. 슬라이더는 지난 기록을 앞뒤로 훑는 **되감기 보조**. 비복원 추출, 이론값 숨김(맞힌 뒤 공개), 성공 횟수 기구, 여러 번 꺼내기, 표본평균 실험.
  - 저울의 끌어 놓기 판정을 꺼내 공용화.
- **단원**: `m2-probability` · `h1-counting` · `h1-set-logic` · `m1-plane-figures` · `m2-exponent-poly` · `prob-binomial`(③의 막대 객체 적용 포함) · `prob-combination-binomial` · `prob-conditional` · `prob-permutation` · `prob-probability` · `prob-discrete` · `prob-estimation` .
- **끝났는지 확인**: 모델이 늘어놓은 경우 수 = sympy 공식 / 같은 시드·같은 횟수면 같은 결과(되감기 재현) / P6 / 화면 점검.
- **위험**: "유치함" 판단이 갈리는 조각 → 구현 전 시안 확인.

### ⑤ coord 그림 객체·곡선·과제

- **깨닫게 할 것**: 식이 그림이 된다 — 벡터는 화살표, 불연속은 빈 점, 수열은 떨어진 점, 원은 한 줄의 식.
