# 부품 기능 요청 목록 (단원 작성 중 나온 것)

단원 작성 담당이 "지금 부품으로는 못 해서 가까운 부품으로 대신한 것"을 모아 둡니다. 한꺼번에 부품을 보강할 때 씁니다.

- balance: `unit` 빈칸 허용(단위 없는 비례식) — e-proportion
- coord: 축 이름(가로 = 밀가루, 세로 = 우유) — e-proportion
- numberLine: 두 줄 수직선(위아래 대응) — e-ratio
- shape: 조각 돌리기(원 부채꼴 잘라 엇갈려 붙이기) — e-circle-area
- shape: 원주(곡선 길이) 재기 — e-circle-area
- shape: 목표 기능("넓이를 12로 만들어 보세요") — e-polygon-area
- solid(새 부품): 직육면체 돌려 보기, 쌓기나무, 전개도 펼치기·접기 — e-cuboid
- shape: 모양을 지키며 꼭짓점 끌기(넓이 12인 직사각형의 가로·세로 바꾸기) — e-divisor-multiple
- numberLine: 범위·칸 수 확대(5000원 등), 점프 화살표 두 줄 — e-whole-ops, e-divisor-multiple
- 세로셈(나눗셈 사다리) 새 부품 — e-divisor-multiple
- numberLine·fraction·areaModel: 소수 표시 옵션 — e-decimal
- 틀린 곳 찾기: ÷ 기호 표시(지금은 번분수로 그려짐), 등식 아닌 식도 — e-fraction-div, e-divisor-multiple
- verify.py: spot 식의 소수를 분수로 정확히 읽기(0.1+0.2=0.3 오판 위험) — e-decimal
- 생성기 조사 도우미(을/를, 이에요/예요)를 util.ts 공용으로 — 여러 단원에 복제됨
- coord: 점 이름표(삼각형·육각형 등 여러 글자) — m1-plane-figures
- shape: 각도 합계 표시, 회전축·연장선 점선, 오목한 각(180° 초과) 표시 — m1-plane-figures
- histogram(새 부품) 또는 table 막대 확장, 줄기와 잎 그림 — m1-data
- 질문 보기 표기: 숫자 뒤 π 붙이기 옵션 — m1-solid-figures
- 강조 표기(==…==) 안에 수식($…$) 허용 — m1-plane-figures
- LITERAL 규칙이 `Rational(360, n)` 같은 계산식도 거부함(우회: 360*Rational(1,n)) — m1-plane-figures
- coord: 정답 곡선 숨기기(채점 전 숨김, 맞히면 보임) — 곡선 손그리기 장면에 필수 — m1-coord-graph
- shape: 함께 움직이는 점(한 점을 끌면 마주 보는 점이 따라옴, 교차한 두 직선 돌리기) — m1-basic-geometry
- ~~verify.py 버그~~ (고침): plot 직선 과제 기울기를 분수("2/3")로 주면 fr() 가 실수로 계산해 "풀 수 있나" 검사 실패(215줄 근처) — m1-coord-graph
- 소인수분해 나무(새 부품: 수를 눌러 두 수로 쪼개기) — m1-prime-factor
- areaModel: 칸 합계(약수의 합) 숨기기 옵션 — m1-prime-factor
- 숫자 문제(solve)에서 객관식 보기 허용 — m1-integer-rational
- balance: 부등호(<) 저울, 음수 곱하기 버튼(부등호 방향 바뀜 체험) — m2-linear-ineq
- numberLine: 점 여러 개를 옮기는 과제 — m2-linear-ineq
- spot: 부등호 토큰 — m2-linear-ineq
- 질문 보기: 식·구간을 보기로("x>−3") — m2-linear-ineq
- 긴 나눗셈(세로셈) 부품 — m2-repeating-decimal (e-divisor-multiple 요청과 같은 계열)
- **verify.py**: 검산식 안의 정수 나눗셈(2**5*2**3/2**4)이 파이썬 실수로 계산됨 — 전역 evaluate 를 유리수로 읽게 검토 — m2-exponent-poly
- coord: 교점 목표 판정(x,y 둘 다), 기울기 목표("3으로 만들기"), 세로선 x=p 그리기 과제, 그림 객체 0개 허용 — m2-simul-eq, m2-linear-func(-eq)
- 생성기에서 String.replace 로 `$$` 를 넣으면 `$` 하나가 됨(replace 특수 패턴) — 작성 주의 — m2-linear-func-eq
- shape: 조각 여러 개 잘라 옮기기, 원의 중심을 끄는 점, 측정값 비율·넓이 이름표 — m2-pythagoras, m2-triangle-quad, m2-similarity
- count tree: 단계마다 다른 물건 목록(모자 3 × 운동화 4) — m2-probability
- simulate: 다시 넣지 않고 꺼내기, 이론값 감추기(맞힌 뒤 보임) — m2-probability
- numberLine·shape: 무리수 점(√2 를 컴퍼스로 옮기기), 원 반지름 정수 외 허용 — m3-sqrt
- areaModel: grow 모드 읽는 값(띠÷Δx) 숨기기, split 결과 식 정리(xx → x², (x+3)²), 음수 칸 — m3-poly-mul
- shape: 수선의 발이 따라오는 점, 측정값 비(높이÷빗변) 표시, 각 호·호 강조, 각도 합 표시 — m3-trig-ratio, m3-circle
- unitCircle: 각 범위 제한(0°~90°) — m3-trig-ratio
- spot: 도 단위 삼각함수(sin 30°) — m3-trig-ratio
- numberLine: 분산·표준편차 값과 편차 막대 표시 — m3-statistics
- 질문 보기: 글자 보기("양의 상관/음의 상관/없음") — m3-statistics
- lesson values: 소수 값 허용(1.4, 1.96) — m3-sqrt
- coord: 슬라이더를 따라 움직이는 점(꼭짓점 (p,q)), 슬라이더 목표("중근이 되게"), 한 점에 여러 값 표시 — m3-quadratic-eq, m3-quadratic-func
- areaModel tiles: 판 크기 확대(x²+7x+12) — m3-factoring
- spot: 허수 I 허용((3+2i)(3−2i) 함정) — h1-complex
- 조립제법·세로 나눗셈 부품 — h1-poly-ops, h1-remainder-factor
