# 실생활 소재 레슨 계획 (real-world)

작성 2026-11-15 · 2판(critic 비평 + 사용자 결정 반영) · 상태: 계획(코드·콘텐츠 변경 없음) · 짝 문서 `docs/plan-widgets-v2.md` (부품 조각 ①~⑧)

## 무엇을 하려는가

미분·적분·넓이처럼 **좌표 위 곡선으로만 설명하던 장면을 땅·길·시간 같은 실제 양으로 바꿔**, "왜 이 계산을 하는지"가 먼저 보이게 합니다. 실생활로 들어가서(도입 질문·손 조작) 수학 표기로 나옵니다(이름 붙이기·요약·수능 연결은 그대로).

**범위(이미 실생활인 장면은 뺀 수)**: 20단원 — 장면 26개(교체 25 + 추가 1), 레슨 안 직접 풀기 9문제, 결론 글 한 줄 4곳. 보류 2단원.

**사용자 결정(2026-11-15)**
- 레슨이 먼저입니다. 연습문제 30개의 실생활 문제는 **별도 계획**으로 미룹니다(끝의 '다음 계획' 절).
- 표식 그림(자동차 같은 작은 그림)을 쓸지는 **시안 두 안(단색 SVG / 점 + 한글 이름표)을 보고 사용자가 결정**합니다.

## 코드를 읽고 알게 된 것

- **빈 곳은 고등 미적분의 손 조작 장면과 직접 풀기**입니다. 초·중등은 도입과 직접 풀기가 이미 실생활입니다(연줄·나무 그림자·사다리·공원·꽃밭·접시·피자). 고등 수학Ⅰ·Ⅱ 단원은 직접 풀기 3문제가 전부 식 계산입니다.
- `math2-definite` 의 `rects` 는 직사각형을 그리지 않고 합 공식을 곡선으로 대신 그린 임시 그림입니다. `math2-velocity` 의 `move` 도 세로축을 수직선처럼 쓰는 임시 그림입니다.
- 좌표평면에는 축 이름·단위 칸이 없습니다. 지금은 읽는 값 이름표에 글로 적습니다(`m1-coord-graph` 의 "시간(분)"). 좌표평면의 숫자 글자는 `fmtNum`(`src/lesson/widgets/coord/frame.ts` )이 만듭니다. 표 부품의 `formatValue` 는 분수 글자용이라 좌표평면에 그대로 못 씁니다(1판의 전제 오류).
- 가장 좁은 화면(382)에서 좌표 그림 영역은 **약 250×190px** 이고 가로·세로 축척이 따로입니다(`frame.ts` : 상자 폭 298 − 여백 48). 한 간격 최소 8px 규칙 때문에 끌어서 닿는 자리는 31칸까지입니다.
- **장면을 더해도 진행 기록은 안전합니다.** 기록은 장면 id 로 저장되고(`src/lesson/state.ts` ) 기준선 비교(`scripts/verify-diff.ts` )는 id 가 사라질 때만 실패합니다.
- **직접 풀기는 레슨당 2~3문제로 형식 검사가 막습니다**(`src/lesson/schema.ts` ). 지금 대부분 3문제라 더할 자리가 없고, 필기는 `장면 id + 문제 id` 로 저장됩니다(`src/lesson/inkKeys.ts` ). 문제를 바꿀 때 **새 문제 id** 를 쓰면 옛 필기가 엉뚱한 문제에 붙지 않습니다(옛 필기는 보이지 않게 될 뿐).
- 조각 ② 의 남은 묶음(`docs/unit-brief-v2.md` 부록 A)과 이 계획이 **같은 장면에서 겹치는 곳**이 있습니다(아래 단계 0).

## 원칙

- **R1. 그림이 곧 수학 객체.** 밭은 "곡선과 축 사이 칠한 영역", 길은 "수직선 띠"입니다. 수학과 무관한 배경 삽화는 넣지 않습니다. 전부 앱이 좌표로 그리는 SVG 라 저작권 문제가 없습니다.
- **R2. 도입 질문과 첫 손 조작은 같은 이야기로, 나올 때는 표기로.** 실생활 장면의 결론 글이나 다음 '이름 붙이기' 장면에 대응 한 줄을 둡니다("밭의 넓이 → $\int_0^3 f(x)\,dx$"). 요약의 "수능에서는"과 직접 풀기 중 2문제 이상은 수능 표기 그대로 둡니다.
- **R3. 바꾸기 우선.** 깨달음이 같고 소재만 달라지면 같은 장면 id 로 교체합니다. 장면 추가는 한 곳뿐이고 초등은 더하지 않습니다.
- **R4. 숫자는 가능하면 그대로.** 곡선·점이 같으면 검산 항목이 안 바뀝니다. 숫자를 새로 짜는 곳은 밭과 상자 두 장면뿐입니다.
- **R5. 음수가 되는 양은 위치·높이로만 부릅니다.** "거리·넓이·양"은 음수가 될 수 없으니, 음수가 나오는 값은 "집 기준 위치(동쪽 +)", "기준 지점에서 본 높이"라고 씁니다.
- **R6. 현실 수치 점검표를 통과해야 합니다**(아래). 검산기는 "시속 4 km 가 걷기에 맞는가"를 못 봅니다.
- 기존 원칙 유지: 끌기는 움직임이 곧 수학일 때만, 보이는 값은 모두 sympy 검산, 382×580 한 화면, 캐릭터·이모지 금지.

- **억지가 되어 제외**: `math2-diff-polynomial` , `math2-limit` · `math2-continuity` , 식의 계산 계열. `math2-area-distance` 의 `hook` 도 다음 장면과 식이 이어져 그대로 둡니다.
- **앞뒤 단원 맞추기**: `math2-diff-coefficient` 가 자동차의 순간 빠르기를 먼저 말하므로, `math2-velocity` 의 `hook`(같은 $t^2$)은 "앞에서 본 자동차, 이번엔 3초인 순간"으로 되짚는 글로 고칩니다(답·숫자 그대로).

## 부품 설계에 더할 것

새 부품은 원 굴리기 하나뿐이고(⑦), 나머지는 기존 부품의 옵션입니다.

**조각 ③-가 (새로 떼어 내는 얇은 조각 — 먼저)**
1. **축 이름·단위**(요청 6·77, ⑤ 에서 앞당김). **읽는 값의 단위는 축에서 저절로 정해집니다**: 가로 좌표 → 가로 단위, 세로 좌표 → 세로 단위, 기울기 → 세로/가로(m/초), 넓이·합 → 가로×세로(같은 단위면 m²). 조합이 어색한 경우(시간 × km/시 = km)만 축 칸에 '곱 단위'·'몫 단위'를 한 번 적습니다. 읽는 값마다 단위를 따로 적지 않으니 어긋날 수 없습니다. 글자는 `fmtNum` 뒤에 붙입니다.
2. **구분구적 직사각형**과 **큰 어림·작은 어림 동시 표시**. 두 합은 **구간에서 계속 오르거나 계속 내리는 곡선에만** 허용(형식 검사 — 아니면 오른쪽 끝 합이 '큰 어림'이 아님. 다항식의 도함수 근 세기는 `coord/poly.ts` 재사용).
3. **곡선 아래 칠하기**와 재질(땅·물·길). 무늬는 넓은 영역에만, 직사각형 조각에는 색만.
4. **축척 같게** 옵션: 가로·세로 한 칸의 화면 길이를 같게(382 화면에서 190×190px, $n=30$ 일 때 조각 폭 약 6px). 이 옵션이 켜진 장면에서만 '지도'·'한 칸 = 10 m'라는 말을 쓰게 합니다.

**조각 ③ 나머지에 추가**
5. 부호별 칠하기와 읽는 값 두 가지(부호 있는 합 / 부호 뗀 합), 두 곡선 사이 칠하기, **맞힌 뒤 칠하기**(기존 '숨긴 정답' 장치를 영역에도).
6. 막대 객체에 구간 폭과 "막대 넓이의 합"(기록표 → 간 거리·들어온 물의 양).

**조각 ⑤ 에 추가**
7. **길 띠**: 좌표평면에 붙는 1차원 띠(가로·세로). 표식 자리 = 지정한 읽는 값. **수직선 부품의 계산·그리기 함수(`src/lesson/widgets/numberLine.ts` 의 `valueAt` · `xOf` · `nlTicks` 등)를 재사용**하고 새로 짜지 않습니다. 요청 81(수직선에서 슬라이더로 움직이는 점)과 한 구현입니다.
8. **계단 표시**: 두 점 사이 가로·세로 변과 길이(요청 64 확장).
9. ⑤ 안의 순서: '구간만 그리기'·'여러 글자 점 이름'을 먼저(실생활은 거의 0 이상 구간, 이름은 "출발"·"정상").
10. 표식 그림 — 사용자가 시안에서 고른 안으로.

**조각 ⑥-가**: 도형판 측정값 단위·이름표(축척 옵션은 뺌 — 설계도 문제는 직접 풀기로 옮김).
**조각 ⑦**: 원 굴리기(요청 9). 굴리는 동작·자국 그리기·검산을 새로 써야 해서 새 부품 수준의 비용입니다.

**`docs/plan-widgets-v2.md` 대응표에서 함께 고칠 줄**(메인): 6·77(축 이름 → ③-가), 77·99 일부(구분구적·칠하기 → ③-가), 81(→ ⑤ 길 띠와 한 구현), 9(원주 재기 → ⑦), 64(계단 표시 포함). 이 문서는 그 표를 고치지 않았습니다.

**검산**: 합·넓이는 앱 값 = sympy(`Sum` · `integrate`), 부호 뗀 넓이는 근에서 끊어 조각마다. 길 띠는 새 검산 없음. 재질·표식·단위 글자는 숫자가 아니라 형식 검사와 점검표로.
